# Temperature Converter (Celsius ⟷ Fahrenheit)

A lightweight and easy-to-use program to convert temperatures between Celsius (°C) and Fahrenheit (°F).

---

## Features
- **Celsius to Fahrenheit Conversion:** $F = (C \times \frac{9}{5}) + 32$
- **Fahrenheit to Celsius Conversion:** $C = (F - 32) \times \frac{5}{9}$
- Simple command-line / interactive interface.
- Accurate calculations rounded to two decimal places.

---

## Conversion Formulas

| Direction | Formula |
| :--- | :--- |
| **Celsius to Fahrenheit** | $F = (C \times 1.8) + 32$ |
| **Fahrenheit to Celsius** | $C = (F - 32) / 1.8$ |
